# code-quest

Monorepo containing both client (`stack`) and server (`server`).

## Structure

- `stack/` - Frontend application (Next.js / React)
- `server/` - Backend server application (Node.js)

## Getting Started

### Frontend (Stack)
```bash
cd stack
npm install
npm run dev
```

### Backend (Server)
```bash
cd server
npm install
npm run dev
```
